# Comfort Hotel Management System - Static HTML Version

Converted from the original PHP/MySQL project to HTML, CSS and JavaScript.

## Run
Open `index.html` or use VS Code Live Server.

## GitHub Pages
Push the complete folder to a GitHub repository, then enable GitHub Pages from Settings -> Pages -> Deploy from branch -> main -> root.

## Demo admin
Username: `admin`
Password: `admin123`

## Important
This is a static demo. Room and booking data are stored in browser localStorage and the demo login uses sessionStorage. There is no real MySQL database or secure server-side authentication.

For production, use a backend such as PHP/Node.js with MySQL/PostgreSQL.
